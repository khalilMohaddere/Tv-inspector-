# Tv-inspector-
TV Inspector is an NLP and Machine Learning project that classifies TV shows based on words and expressions extracted from subtitles and closed captions. It uses text preprocessing, feature extraction, and classification models to identify TV series, with a Flask web application for interactive predictions.
